# top-basic-informational-site

A Basic node server as part of the the odin project curriculum that allows browser user to request various html pages from the server,
the server then sends a response by retriving and sending the html page to the client base on the url request. 

## Teck Stack

- html
- javascript 
- node.js

## server request usage 

- localhost:3000/ -> response (index.html)
- localhost:3000/about -> response (about.html)
- localhost:3000/contact-me -> response (contact-me.html)
- unknown url path to the server -> reponse (404.html)
